# Break the AI: Game Guide

## Game at a glance
Two teams chat with an AI guard, VaultBot, and try to trick it into saying a secret 4-digit code. There are 3 rounds of about 3 minutes, played at the same time. Each round has a stricter guard and a new code. The team with the most points wins.

| Time | What happens |
| --- | --- |
| 0:00 – 3:00 | Explain the game |
| 3:00 – 13:00 | 3 rounds, about 3 minutes each |
| 13:00 – 15:00 | Tiebreaker if needed, final scores, winner |

You need 2 laptops (1 per team), Wi-Fi and power. Setup is in the [README](README.md).

## What to announce
> "Welcome to Break the AI! Each team has a robot guard called VaultBot, and it is hiding a secret 4-digit code. Your job is to trick it into telling you.
>
> Chat with it on your laptop. Type, or press Speak and say it out loud. When you find the code, type it in the code box.
>
> There are 3 rounds of about 3 minutes, and each guard is harder than the last. The first team to crack the vault scores the most, and Round 3 is worth double. Stuck? A hint appears halfway through each round.
>
> After every message, a different teammate takes the keyboard. Ready? Round one!"

## Rules
1. After every message, a different teammate types or speaks.
2. Talk to the guard only in the chat. No other AI tools, no internet search, no hacking the website.
3. Keep it friendly. No insults and no personal information.
4. A wrong code locks your code box for 10 seconds, so do not guess numbers.
5. Do not look at the other team's screen.
6. The game master's decision is final.

## Points and tiebreaker
Round 3 is worth double. The highest possible score is 12, the same as Mute. Points count toward the night's total across all four games.

| Round | Guard | First to crack | Second to crack |
| --- | --- | --- | --- |
| 1 | Easy: friendly, but falls for a good story | 3 points | 1 point |
| 2 | Medium: strict, and a censor blocks the code in digits | 3 points | 1 point |
| 3 (double) | Hard: maximum security | 6 points | 2 points |

A vault nobody cracks scores 0. A team that breaks a rule scores 0 for that round, and the other team gets at least 3 points.

**Tiebreaker:** if points are equal, the team with more vaults wins, then the team with the lower total crack time. If the times are within 10 seconds, play one sudden-death round with a new guard. The first correct code wins. The tiebreaker adds no points.
